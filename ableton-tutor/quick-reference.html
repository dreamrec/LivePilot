Ableton Quick Reference

Mac only
No Audio Session Arrangement Edit Drag Zoom Recording Takes Workflows

No Audio After Session View

  1. Click Stop All Clips if Session clips are still running.
  2. Press fn + F10 for Back to Arrangement.
  3. Put the playhead over actual Arrangement clips.
  4. Press Space.

LivePilot/API: clear the orange override with back_to_arranger=false; verify arrangement_override=false.

Session View clips + scenes

Tab switch views

Toggles Arrangement View and Session View.

Enter launch selected slot

Launches the selected clip/slot. If a scene launch slot is selected, launches that scene.

Scene launch is far right

Click the small triangle in the numbered row under the Main track to launch the whole row.

One clip only takes over one track

Other tracks can keep playing from Arrangement until you launch their Session clips too.

Arrangement timeline

Option + 2 focus Arrangement

Use before Arrangement key commands if shortcuts seem to hit the wrong panel.

fn + F10 Back to Arrangement

Use after Session clips took over. LivePilot should clear the matching API flag by setting back_to_arranger=false.

Space play/stop

Starts or stops the transport from the current position.

Double-click Stop = 1.1.1

Most reliable way to return the song position to the start.

Option + Left/Right

Jump to previous/next clip edge or locator when Arrangement has focus.

Arrangement Edits clips

Cmd + A select all

Applies to the focused area. Click the Arrangement first, or press Option + 2.

Cmd + J merge MIDI clips

Select adjacent MIDI clips, or drag a time selection across them, then Consolidate.

Cmd + E split clip

Click where the split should happen, or select a time range first.

Cmd + D duplicate

Duplicates the selected clip or selected time range immediately after itself.

Mouse + Drag move fast

Move a clip: drag its top bar

The colored title bar moves the whole clip. Dragging inside the MIDI/waveform area usually selects time inside the clip.

Option + drag = copy

Use when you want another copy. Do not hold Option when you only want to move.

Cmd while dragging ignores grid

Use for tiny timing moves. Leave Cmd alone if you want clips snapped cleanly to bars.

Shift-click adds clips

Shift-click individual clips, or drag a box around a group before moving them together.

Looping repeat area

Cmd + L toggle loop

Turns the Arrangement loop brace on or off.

Cmd + Shift + L

Selects the material inside the loop brace.

Loop does not always jump playback

Move the playhead to the loop start or inside the loop before pressing Space.

Zoom + Fit see faster

+ / - zoom time

Zooms in/out around the time ruler or focused editor area.

Cmd + + / Cmd + -

Changes Live's window/interface zoom level.

Z zoom to selection, X back

Use after selecting a clip, time range, or notes.

W fit width, H fit height

Fast reset when the Arrangement or MIDI editor view feels lost.

Record Audio Arrangement

Cmd + T audio track

Creates a new audio track.

C arm selected track

Record-enables the selected track.

fn + F9 record

Arrangement Record on Mac keyboards where F9 is a media key.

Monitoring: Auto / In / Off

Use Auto for normal recording, In to always hear input, Off to avoid Live input monitoring.

Takes + Comping loop passes

Cmd + Option + U

Show or hide take lanes.

T audition take lane

Hear the selected take lane.

Enter promote take section

Adds the selected take-lane area to the main track lane.

Shift + Option + T

Adds a take lane manually.

Mac Function Keys important

Ableton F-keys may need fn

If F9/F10 changes brightness or volume, hold fn with the function key.

Most-used Mac F-keys

fn + F9 record. fn + F10 Back to Arrangement.

Fast Workflows do this

No audio after Session View

  1. Stop All Clips.
  2. fn + F10.
  3. Move playhead over Arrangement clips.
  4. Space.

Launch a whole Session row

  1. Find the row you want.
  2. Click the far-right scene triangle.
  3. Use Stop All Clips when done.

Loop-record multiple takes

  1. Select the Arrangement range.
  2. Cmd + L.
  3. Arm track with C.
  4. fn + F9.
  5. Space to stop.

Try one part over another

  1. Put clips into Session slots.
  2. Build a test scene row.
  3. Use Verse 1 clips except the Verse 3 bass clip.
  4. Launch the scene row.

Move MIDI to bar 1

  1. Tab to Arrangement.
  2. Select the MIDI clips.
  3. Drag the colored top bar left to 1.1.1.
  4. Use W to fit width if the start is hidden.

Merge two MIDI regions

  1. Select both adjacent MIDI clips.
  2. Or drag a time selection across both.
  3. Press Cmd + J.
  4. The result is one consolidated MIDI clip.
